**Status:** ⏳ in progress

Checklist: **`docs/guide-to-writing-plans.md`**. Vala: **`docs/coding-standards.md`** via **`docs/coding-standards-router.md`**.

**ℹ️** Parent: [`0.3-vala-ibus-sherpa-onnx.md`](0.3-vala-ibus-sherpa-onnx.md) (IBus engine + `.deb`). This slice is UX + prefs + model install story.

**ℹ️** Carry forward **Agent rule** from 0.3: do **not** mutate the user’s GNOME/IBus session, run `sudo`/`pkexec` against their machine, or `dpkg -i` without an explicit ask. Repo edits + local `ninja` / `dpkg-buildpackage` OK.

## Purpose

- **🔷** Real **Preferences** for the IME (GNOME’s “Preferences” / component `<setup>`), not a dead menu entry.
- **🔷** First-class **hotkey** editor (press-a-key capture) in prefs — same idea as RooTerm `RowKeySelect` (copy the small pattern; do not depend on RooTerm).
- **🔷** User prefs in one **`GLib.KeyFile`**: `~/.config/ibus-sherpa-onnx/settings.ini` (not GSettings; not one file per flag). `model` stays a symlink beside it.
- **🔷** Clear **listening feedback** so the user is never guessing: animated preedit `...`, top-bar / panel **symbol**, optional **desktop notification**.
- **🔷** Fix **terminal shortcuts** broken while this IME is active (`Ctrl+C`, `Ctrl+Shift+R`, etc.) — caused by blanket `forward_key_event`.
- **🔷** While **listening**, any normal key (not the toggle) **stops dictation** (mic off / clear preedit), then the key is delivered to the client — typing interrupts recording.
- **🔷** Fix **VTE / plain keys** still eaten or broken after Phase A’s modifier pass-through: **Enter**, **Delete/Backspace**, arrows, and similar non-printable keys must reach the terminal (and Text Editor); do not leave the client unable to submit or edit after dictation or while Sherpa is selected.
- **🔷** Prefs **Select model** (**560** / **1120** ms only; default **None**). On close: download+extract as user → **polkit moves** into system `models/`; then set **user** `model` symlink to that tree (no polkit for selection).
- **🔷** System holds **multiple** installed trees; **active choice is always the user symlink** `~/.config/ibus-sherpa-onnx/model` → one system dir. No system-level “active model” symlink.
- **🚫** No separate “user override model tree” / parallel user `models/` store in the prefs story.
- **🚫** No `MODELS_DIR` / model-path environment knobs. **🚫** No hand-crafted `ln -s` for normal install.
- **🚫** Privileged helper must **not** download from the network (polkit = move into `models/` + cache cleanup only).
- **🚫** No mscorefonts-style silent `postinst` network download. Engine `.deb` stays small.

## Model locations

**Less config:** system stores weights; user config is only which one (a symlink). No path env vars.

### System (shared store — not “the active model”)

```
/usr/share/ibus-sherpa-onnx/models/<nemotron-dir-name>/
```

Many directories may coexist. There is **no** `/usr/share/ibus-sherpa-onnx/model` active symlink.

### User (active selection)

```
~/.config/ibus-sherpa-onnx/model  →  /usr/share/ibus-sherpa-onnx/models/<chosen>/
```

Prefs / engine create or retarget this symlink as the user (no polkit). That is the only “which model” config.

### User staging (download only)

```
~/.cache/ibus-sherpa-onnx/download/<chunk-or-dir>/   # archive + unpack (as user)
```

After polkit **move**, delete that cache tree (and leftover `.tar.bz2`).

### Engine / first-run resolution

Load **`~/.config/ibus-sherpa-onnx/model`** (must resolve to a model directory).

If that path is **missing**:

1. If `/usr/share/ibus-sherpa-onnx/models/` has one or more complete installs → **auto `ln -sfn`** to the **largest** installed tree (by on-disk size), then use it. New users on a machine that already has models get a working default without opening prefs.
2. If no system models yet → **still register the engine** (no sherpa load); prefs starts at **None**. On toggle (or other “try to dictate”): do **not** open the mic — send a **desktop notification** (“No speech model installed”) with a button / default action that launches **`ibus-setup-sherpa-onnx`** (`app.open-preferences` on the engine `GApplication`). **🚫** Do not exit the engine process solely because the model is missing.

If `model` already exists (symlink or, **💩** legacy real directory), use it as-is until prefs changes the selection.

**ℹ️** Package creates `/usr/share/ibus-sherpa-onnx/models/` (empty). It does **not** ship weights.

## Download + polkit install flow

On prefs close with a selected model that is not already active:

1. **User download** (no privileges): prefs uses an in-process Soup downloader into `~/.cache/ibus-sherpa-onnx/download/...`. Show a **`Gtk.ProgressBar`** (bytes / total, optional rate text).
2. **User extract** (no privileges, in-process): unpack the `.tar.bz2` with **libarchive** in Vala (not `tar`/`GLib.Process` shell-out). Same progress bar, label switches to “Extracting...”. Fraction from compressed bytes consumed / archive size (or uncompressed written / sum of entry sizes if easy). Yield to the main loop so the bar updates (async or idle chunks).
3. **Polkit move** (privileged, narrow): `pkexec` a small helper that:
   - **moves** (not copies) the unpacked dir into `/usr/share/ibus-sherpa-onnx/models/<dir>/` (skip move if that dir already exists and looks complete);
   - **deletes** the user’s cache staging for that download;
   - does **not** touch any “active model” symlink (that is user-owned).
4. **User symlink** (no privileges): `ln -sfn` `~/.config/ibus-sherpa-onnx/model` → the chosen system tree.
5. If the variant is **already** under `models/` and the user only changed selection: only step 4 — **no** download, **no** polkit.
6. If download/extract/move fails: leave prior user symlink intact when possible; clear partial cache on cancel when practical.
7. **After a successful install / first model link:** the running engine (if any) still has no `Transcriber` or an old one — prefs runs **`ibus restart`** (no confirm; restart is cheap) so dictation picks up the model. README mentions the same. Switching an already-loaded engine to another *installed* tree also restarts unless we add hot-reload later (**💩**).

### Extraction progress (Vala / libarchive)

Shelling out to `tar` gives little usable progress without awkward checkpoint parsing. Prefer **in-process libarchive** (`libarchive` pkg + system Vala vapi):

- **🔷** `✔️` `Archive.Read` + `Archive.WriteDisk` unpack into `~/.cache/.../download/<dir>/` (worker + `Idle` → UI); polkit moves into system `models/`.
- **🔷** `✔️` Extract progress on the same bar (`position_compressed()` / archive size); label “Extracting...”. Updates **inside** `read_data_block` (not only per entry) so large ONNX members do not freeze the UI.
- **🔷** `✔️` Keep UI responsive (`GLib.Idle` from the worker).
- **🔷** `✔️` SHA-256 of archive vs packaged `data/checksums/*.sha256`, then write tree `.sha256` stamp (needed for `Models.ready`).
- **🚫** Do not use silent `tar xf` with only a pulsing indeterminate bar as the primary UX (pulse OK only as brief fallback).
- **💩** Exact uncompressed totals are nicer but optional; compressed-stream fraction is enough for 0.4.

Helpers:

- Prefs Vala downloader (primary UX) — **✔️**.
- `/usr/libexec/ibus-sherpa-onnx-install-model` (`scripts/install-model.sh`) — **✔️** polkit **mv** into `models/` + **rm** archive (name allowlist). No user-config writes as root.
- Polkit policy `data/polkit/org.roojs.ibus-sherpa-onnx.policy.in` — **✔️**.
- [`scripts/cli-fetch-nemotron-model.sh`](../../scripts/cli-fetch-nemotron-model.sh) — **✔️** CLI twin of prefs (cache → pkexec → user symlink).

**🚫** Do not download as root / inside the polkit helper.  
**🚫** Do not maintain a system-wide active-model symlink.  
**🚫** Do not embed sudo password prompts in Vala — **pkexec** only.

## Panel badge (not “en”)

GNOME’s input-source indicator falls back to the **language** code when `<symbol>` is empty — hence useless **`en` / `en2`**.

- **🔷** Set component XML `<symbol>voi</symbol>` (short for voice; alternatives considered: `mic`, `dict`, `stt` — pick one and keep it).
- **🔷** Keep `<language>en</language>` so Settings still groups under English.
- **🔷** Runtime: idle badge **`voi`**; listening **`...`** or **`rec`** (via property / engine symbol update — whatever GNOME actually mirrors to the top bar; verify on Shell 48).
- **🚫** Do not leave symbol empty. **🚫** Do not use bare `en` as the badge.

## Listening feedback (engine)

- **🔷** While listening and no partial yet: timer updates preedit through `.` → `..` → `...` (or similar); stop animation when partials arrive or listening stops.
- **🔷** Sync panel **symbol** with listening state (`voi` ↔ `...` / `rec`); property label can stay “Mic off” / “Listening...”.
- **🔷** If notifications enabled: `GLib.Notification` / `GNotification` via a session bus — short “Listening...” / “Mic off” on toggle (no spam on every partial).
- **🔷** **No model:** engine stays up without loading sherpa; on toggle → notification (always, not gated by the listening-notify pref) + action to open Preferences. See Engine / first-run resolution.
- **💩** Panel property row can stay; not the primary cue.

## Key pass-through fix

- **🔷** Toggle combo: handle and `return true`.
- **🔷** Keys with **Ctrl / Alt / Super / Meta / Hyper** (and not the toggle): **`return false`** — do not forward (restores terminal and app accelerators).
- **🔷** Plain typing (no those mods, or Shift-only for capitals): keep whatever works on GNOME (capability-aware `forward_key_event` + `true`, or `false` if sufficient after retest).
- **🔷** **Non-printables** (Return, BackSpace, Delete, Tab, arrows, Home/End, etc.): must not stay stuck in a forward-only path that VTE ignores — retest; likely **`return false`** so the client indexes/handles them (same failure mode as “can’t press Enter or Delete after dictation”).
- **🔷** While **listening**: on any non-toggle key (printable or edit key), **stop listening** first (clear listening UI / preedit), then apply the pass-through rules above so the interrupting key reaches the app.
- **🔷** Retest: GNOME Text Editor typing + VTE `Ctrl+C` / `Ctrl+Shift+R` / **Enter** / **Backspace** / **Delete** with Sherpa selected; interrupt listening by typing a letter.

## Explicit non-goals

- **🚫** `postinst` network download of the model
- **🚫** Shipping Nemotron weights inside the engine `.deb`
- **🚫** Network download inside the polkit / root helper
- **🚫** System-wide `/usr/share/.../model` active symlink
- **🚫** Parallel user `models/` tree as the normal install target (user path is symlink only)
- **🚫** GSettings schemas for engine prefs (KeyFile instead)
- **🚫** One config file per boolean / hotkey
- **🚫** Linking / depending on OLLMchat / `libochf` / `OLLMrpc` at build or runtime
- **🚫** Relying on shelling out to `tar` for the prefs extract UX (CLI script may still use `tar`)
- **🚫** `MODELS_DIR` / other model-path environment variables
- **🚫** Requiring a hand-crafted `ln -s` after fetch for normal use
- **🚫** Leaving multi-hundred-MB trees in `~/.cache` after a successful install
- **🚫** GNOME Shell extension for a custom tray icon
- **🚫** Full ibus-setup clone (many pages); one prefs window is enough
- **🚫** Depending on RooTerm at build/runtime (copy pattern only)
- **🚫** Changing the user’s session from the agent without ask
