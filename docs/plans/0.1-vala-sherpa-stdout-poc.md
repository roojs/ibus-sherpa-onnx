## Phase 3 — Stdout streaming PoC

**Why:** User-facing first win: live transcript on **stdout**.

**🔷** `⏳` `src/main.vala` (or `src/stt_poc.vala`):

1. Init GStreamer
2. Pipeline: `pulsesrc` or `pipewiresrc` → convert to **F32LE mono 16 kHz** → `appsink`
3. On `new_sample`: map buffer → `float[]` → `accept_waveform` → decode while ready → if text changed, `print ("%s\n", text)` (or `\r` overwrite — pick one and stick to it)
4. Quit on Ctrl+C / SIGINT

**🔷** Threading for this PoC:

- Decode may run on GStreamer streaming thread (same as Gemini notes).
- **Stdout only** — no GTK; printing from the worker is acceptable for PoC.
- **💩** If stdout races look ugly, queue prints via `GLib.Idle.add` anyway (prep for GTK).

**🔷** `⏳` Build via Meson or a one-liner `valac` with:

- `--pkg gstreamer-1.0 --pkg gstreamer-app-1.0`
- `-X -I…/include -X -L…/lib -X -lsherpa-onnx-c-api`
- `sherpa-onnx.vapi` + `main.vala`

**🔷** Model paths: CLI args or env pointing at `models/sherpa-onnx-nemotron-…/{encoder,decoder,joiner,tokens}`.
