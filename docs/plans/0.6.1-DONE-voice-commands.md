# 0.6.1 DONE Voice commands

Parent: [`0.4-DONE-prefs-feedback-models.md`](0.4-DONE-prefs-feedback-models.md)

## Purpose

🔷 Voice commands use a **suggested phrase prefix** (not an always-on wake word) — OS default from `/etc/os-release` `ID` (`okay ubuntu` / …, else `okay linux`), baked into each command’s default full phrase; user can edit.
🔷 Three commands: paragraph, line break, stop — each pref is the **full** spoken phrase.
🔷 Prefs UI for those phrases (+ record-to-test mic control).
🔷 Match on ASR **endpoint** (trailing silence); strip phrase; inject `\n\n` / `\n` / stop.

## Why not bare phrases

🔷 Do **not** match naked “line break” / “new paragraph” alone — those show up in normal speech.
🔷 Each command is a **full phrase** including the suggested prefix (defaults only; user can rewrite).

🔷 `GLib.Environment.get_os_info(GLib.OsInfoKey.ID)` → `okay <id>`; missing → `okay linux`.
✔️ User edits win; do not reset on later OS detection.

## Config

✔️ `settings.ini` `[general]`:

```ini
voice-commands=true
voice-paragraph=okay ubuntu paragraph
voice-line-break=okay ubuntu line break
voice-stop=okay ubuntu stop
```

✔️ Missing keys seeded from OS `ID` + fixed tails.

## Prefs UI

✔️ Tabs: General + Voice commands.
✔️ Master `voice-commands` toggle (default on); hides phrase rows when off.
✔️ `RowMicText` + AT-SPI hotkey synth to start listening in the entry (IBus `property_activate` did not reach this engine).
✔️ Prefs close → `ibus restart` reloads engine config.

## Matcher (engine)

✔️ On each endpoint when `voice-commands` is on:

1. Normalize (`ok`/`okay`, case, spaces, strip punctuation).
2. Last ≤4 words as candidate.
3. RapidFuzz `best_ratio` vs three phrases, cutoff **80**.
4. Strip matched words; paragraph `\n\n` / line break `\n` / stop mic.

✔️ RapidFuzz C++ bridge + VAPI under `src/vapi/`.

ℹ️ Command mid-sentence with no pause may miss — acceptable for v1.

## Done when (verified)

- Defaults use `okay <os-release ID>` (or `okay linux`) in all three fields.
- Edits stick after restart.
- Speaking each phrase does paragraph / line break / stop without leaving the phrase in the doc.
- Record-in-prefs clears text and starts listening.
